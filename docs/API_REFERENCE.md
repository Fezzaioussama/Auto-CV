# API Reference

All API routes are defined in `src/autocv/app.py`. Routes return JSON except
`/api/render-latex`, which returns a PDF on success.

## `GET /`

Renders the main CV optimizer page.

## `GET /interview`

Renders the interview preparation page.

## `GET /api/llm/health`

Reports the active LLM provider/configuration. This endpoint is diagnostic and
does not expose API keys.

### Success Response

```json
{
  "success": true,
  "source": "local",
  "config": "LLM provider: local | base_url=http://localhost:8000/v1 | api_key=none | default_model=my-model"
}
```

`source` is either `local` or `openrouter`. This route reports configuration;
it does not make a test completion request.

## `POST /api/parse-job`

Parses a raw job description into structured fields.

### Request

```json
{
  "text": "Senior Backend Engineer...\nRequirements:\n- Python\n- Docker"
}
```

### Success Response

```json
{
  "success": true,
  "text": "cleaned or original job text",
  "raw_text": "job text",
  "skills": ["python", "docker"],
  "requirements": ["5+ years of Python experience"],
  "qualifications": ["Master"],
  "company_info": {
    "company_name": "Example"
  },
  "sections": {
    "requirements": true
  }
}
```

### Error Response

```json
{
  "error": "No job description provided"
}
```

## `POST /api/analyze-cv`

Analyzes a CV against an already parsed or raw job description.

### Request

```json
{
  "cv_latex": "\\documentclass{article}\\begin{document}...\\end{document}",
  "job_description": {
    "skills": ["python", "docker"],
    "requirements": ["Experience with Python and Docker"]
  }
}
```

### Success Response

```json
{
  "success": true,
  "analysis": {
    "overall_score": 75,
    "skills_match": {
      "matched": ["python"],
      "missing": ["docker"],
      "total_job_skills": 2
    },
    "recommendations": ["Emphasize Python API experience"]
  }
}
```

The exact `analysis` object may contain additional fields from `src/autocv/matcher.py`.

## `POST /api/optimize-cv`

Analyzes and optimizes a LaTeX CV for a parsed job description.

### Request

```json
{
  "cv_latex": "\\documentclass{article}\\begin{document}...\\end{document}",
  "job_description": {
    "raw_text": "Full job offer...",
    "skills": ["python", "postgresql"],
    "requirements": ["Build backend services"]
  }
}
```

### Success Response

```json
{
  "success": true,
  "analysis": {
    "overall_score": 80,
    "skills_match": {
      "matched": ["python"],
      "missing": ["postgresql"],
      "total_job_skills": 2
    },
    "recommendations": []
  },
  "optimized_latex": "\\documentclass{article}...",
  "rewritten_sections": ["Experience", "Skills"],
  "proposed_additions": [
    {
      "type": "skill_gap",
      "title": "PostgreSQL project",
      "reason": "The offer asks for PostgreSQL experience.",
      "latex": "\\section{Projects}\n..."
    }
  ]
}
```

### Notes

- `rewritten_sections` is empty when section-level LLM rewriting did not
  produce usable results.
- `proposed_additions` are optional snippets. The frontend lets the user insert
  them manually.

## `POST /api/render-latex`

Compiles LaTeX into a PDF.

### Request

```json
{
  "latex": "\\documentclass{article}\\begin{document}Hello\\end{document}"
}
```

### Success Response

Returns binary PDF content:

```text
Content-Type: application/pdf
Content-Disposition: attachment; filename=cv_YYYYMMDD_HHMMSS.pdf
```

### Error Response

```json
{
  "error": "LaTeX compilation failed",
  "details": "pdflatex output..."
}
```

Common errors:

- `No LaTeX content provided`
- `pdflatex not found. Please install a LaTeX distribution.`
- `LaTeX compilation timed out`
- `PDF file was not created`

## `POST /api/interview/questions`

Generates interview questions from a CV and/or job description.

### Request

```json
{
  "cv_latex": "\\documentclass{article}...",
  "job_description": "Senior Backend Engineer...",
  "level": "senior",
  "domains": ["coding", "system_design", "technical", "behavioral"],
  "count": 6,
  "extra_instructions": "Focus on async Python and scalability."
}
```

### Success Response

```json
{
  "success": true,
  "detected_level": "senior",
  "role_title": "Backend Engineer",
  "questions": [
    {
      "id": 1,
      "domain": "coding",
      "domain_label": "Coding",
      "level": "senior",
      "title": "Rate limiter",
      "question": "Implement...",
      "rationale": "The role mentions high-throughput services.",
      "language": "python",
      "starter_code": "def solve(...):\n    pass",
      "evaluation_criteria": ["Correctness", "Complexity"]
    }
  ],
  "fallback": false,
  "attempts": 1
}
```

If the LLM cannot produce usable JSON, `fallback` can be `true`.

## `POST /api/interview/review`

Reviews one answer or code solution for one generated interview question.

### Request

```json
{
  "question": {
    "id": 1,
    "domain": "coding",
    "question": "Implement a rate limiter..."
  },
  "answer": "def allow_request(...): ...",
  "language": "python",
  "job_description": "Senior Backend Engineer..."
}
```

### Success Response

```json
{
  "success": true,
  "review": {
    "score": 72,
    "verdict": "Solid, with gaps",
    "summary": "The solution is mostly correct...",
    "strengths": ["Clear structure"],
    "improvements": ["Handle concurrency"],
    "follow_up_questions": ["How would this work across multiple nodes?"],
    "model_answer": "A strong answer would...",
    "is_coding": true,
    "correctness": "partially_correct",
    "complexity": {
      "time": "O(1)",
      "space": "O(n)"
    },
    "optimized_code": "def allow_request(...): ...",
    "optimized_notes": "Uses constant-time checks.",
    "fallback": false
  }
}
```
